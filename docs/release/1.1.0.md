# Làm 1 Chạm 1.1.0

- **Danh sách phần mềm đồng bộ với Web Admin:** đăng nhập xong, phần mềm lấy danh sách ở Admin › Ứng dụng. Thêm, sửa, bật/tắt ứng dụng trên Admin là laptop nhận ở lần đăng nhập sau.
- **Cài cả bằng link tải** (ngoài WinGet): chỉ chạy file có chữ ký số của hãng tin cậy; ứng dụng có nhiều phiên bản (Office, Kaspersky, ESET) chọn được phiên bản trước khi cài.
- **Ưu tiên bản tiếng Việt** khi cài qua WinGet và trong các link tải.
- Ứng dụng chưa cài tự động được hiện mờ kèm lý do.
- Kết quả mỗi lượt cài hiện ở Admin › Lịch sử cài.
- Trang tải chuyển sang https://dunglam.top/tai-xuong (đường dẫn cũ tự chuyển).

Các lưu ý của bản 1.0.0 vẫn áp dụng: EXE chưa ký số (Windows có thể cảnh báo, bấm **More info › Run anyway**); chia ổ đĩa và tắt BitLocker chỉ dùng khi khách đã sao lưu và máy cắm sạc.
