# Làm 1 Chạm 1.1.3

Cài phần mềm nhanh hơn.

- **Ưu tiên cài bằng link tải** khi Admin có link và cách nhận biết ứng dụng; WinGet làm dự phòng. Link vẫn bắt buộc chữ ký số của hãng tin cậy.
- **Tải trước** file cài của các ứng dụng tiếp theo trong lúc đang cài ứng dụng khác.
- Kiểm tra "đã cài sẵn" nhanh hơn (đọc danh sách ứng dụng của Windows thay vì chạy winget).
- Link lỗi (không tải được, sai chữ ký) thì tự chuyển sang WinGet.

Giữ nguyên mọi thay đổi của 1.1.2. EXE chưa ký số: Windows có thể cảnh báo, bấm **More info › Run anyway**.
