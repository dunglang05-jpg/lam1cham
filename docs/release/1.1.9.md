# Làm 1 Chạm 1.1.9

- **Trang Phần mềm gọn hơn:** ứng dụng dàn thành thẻ nằm ngang thay vì một cột dọc dài.
- **Mới: Wi-Fi miễn đăng nhập.** Đang nối Wi-Fi của cửa hàng (khai báo ở Admin › Cài đặt) thì mở phần mềm là vào thẳng. Windows 11 24H2 cần bật Vị trí (Location).
- **Mới: Đưa Word, Excel, PowerPoint ra desktop** trong Cài đặt & Tối ưu (máy đã cài Office). Hoàn tác được.
- **Phiên bản Office, Kaspersky, ESET:** chỉ hiện mũi tên "Phiên bản ▾", bấm vào mới sổ ra để chọn.

Giữ nguyên các thay đổi của 1.1.3–1.1.8. EXE chưa ký số: Windows có thể cảnh báo, bấm **More info › Run anyway**.
