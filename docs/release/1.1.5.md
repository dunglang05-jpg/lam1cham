# Làm 1 Chạm 1.1.5

- **Thanh tiến trình chạy liên tục:** thấy rõ đang tải bao nhiêu %, bao nhiêu MB, đang chạy trình cài bao lâu, đang xác minh. Áp dụng cho mọi tác vụ, kể cả tối ưu Windows và dọn dẹp.
- **Sửa lỗi:** ứng dụng đã cài sẵn bị báo "Cần kiểm tra — Không xác minh được. Chưa chạy." Nay báo đúng "Đã có sẵn".

Giữ nguyên mọi thay đổi của 1.1.4 (không chờ RAM trống) và 1.1.3 (cài bằng link trước, tải trước khi đang cài). EXE chưa ký số: Windows có thể cảnh báo, bấm **More info › Run anyway**.
